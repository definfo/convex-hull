
F. U2
每次测试时间限制 1 秒
每次测试内存限制 256 兆字节

最近 Vasya 学到，给定两个 x 坐标不同的点，恰好可以画出一条形如 y=x^2+bx+c 的抛物线通过这两个点，其中 b 和 c 为实数。我们称这样的抛物线为 U 形抛物线。

Vasya 在平面上画了若干个坐标为整数的不同点，然后通过每对 x 坐标不同的点画了一条 U 形抛物线。画面变得有些凌乱，但 Vasya 仍然想数出有多少条画出的抛物线内部不包含任何已画的点。请帮助 Vasya。

U 形抛物线的内部区域是指当 y 轴方向朝上时，严格位于抛物线上方的那部分平面。

输入
第一行包含一个整数 n（1≤n≤100000）— 点的数量。

接下来 n 行描述这些点，第 i 行包含两个整数 xi 和 yi — 第 i 个点的坐标。保证所有点互不相同，且坐标的绝对值不超过 10^6。

输出
仅输出一行一个整数 — 经过至少两个给定点且内部不包含任何给定点（不包括抛物线本身）的 U 形抛物线的数量。

样例
输入
3
-1 0
0 2
1 0
输出
2
输入
5
1 0
1 -1
0 -1
-1 0
-1 -1
输出
1
注释
下图分别是每个样例中经过至少两个给定点的所有 U 形抛物线。内部不包含任何给定点的 U 形抛物线用红色标出。
